# CFH Search

CFH Search adds a Windows interface to ripgrep for finding literal text in a chosen folder. It reads files without modifying them and shows matching paths and line numbers. The search engine honors ripgrep's default ignore rules and skips hidden files and binary data; a search may therefore omit files. The interface limits displayed results to 1 MB.
